# Novedades · Feedback Design Skill

## v1.2.0 · Noviembre 2026
- Plantilla Word institucional A4, editable, con portada, resumen, indicadores y próximos pasos; acceso desde Aplicaciones y Descargas.
- Sitio con menú móvil y ajustes de contraste para etiquetas y botones.
- Generador de instrucciones que cambia según pieza, formato, tipo de entrega y restricciones.
- Ejemplos correspondientes a cada pestaña de aplicación y comparaciones **demostrativas**.
- Descarga individual de los seis gráficos SVG en la sección Manual de visualización.
- Ocho láminas PowerPoint editables, con datos simulados claramente señalados.
- Kit SVG de flecha, portadilla y retícula de doce columnas.
- Guías de instalación para ChatGPT, Claude.ai y Claude Code.
- Checklist interactiva de calidad, con copia de resultados.
- Metadatos Open Graph para compartir el enlace.
- Aviso de uso de marca, tipografías y procedencia de activos.

# Control de calidad y criterios de aceptación

## Fidelidad editorial — obligatorio
- [ ] Ningún texto suprimido, añadido, resumido o parafraseado sin permiso.
- [ ] Cifras, unidades, fechas, fuentes y acentos coinciden con el material original.
- [ ] Orden de láminas y elementos conservado, salvo instrucción explícita.
- [ ] Celdas y etiquetas de tablas íntegramente preservadas.

## Identidad visual — obligatorio
- [ ] Blanco como base o transparencia real según petición; sin degradados.
- [ ] Coral #F04D51 y cian #0BB0D2 solo donde aportan estructura.
- [ ] Baskerville MT Std en títulos; Akzidenz-Grotesk Pro en cuerpos cuando estén disponibles.
- [ ] Retícula editorial, jerarquía, márgenes y espacio negativo.
- [ ] No hay iconografía decorativa genérica ni exceso de elementos.
- [ ] Bordes de recorte limpios, no rasgados y sin difuminado.

## Veracidad — obligatorio
- [ ] Referencias a territorio, personas, industrias y culturas con sustento verificable.
- [ ] No se presentan imágenes sintéticas como fotografías documentales.
- [ ] No se inventan logotipos, cifras ni fuentes.
- [ ] Sin fuentes tipográficas comerciales redistribuidas.

## Entrega — obligatorio
- [ ] Ratio, tamaño y fondo coinciden con el pedido.
- [ ] Si se promete PPTX editable, contiene elementos nativos editables.
- [ ] No hay texto fuera de área, objetos cortados ni superposiciones accidentales.
- [ ] El archivo final abre correctamente y la vista previa se ha revisado.

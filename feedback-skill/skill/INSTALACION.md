# Instalación Feedback Design Skill v1.2 · ChatGPT

La skill es un conjunto de instrucciones y referencias. No incluye tipografías comerciales ni genera archivos por sí misma.

## ChatGPT con Skills habilitadas
1. Descarga `feedback-design-skill-v1.2.0.zip` desde el sitio Feedback.
2. Abre la interfaz de **Skills** de ChatGPT, selecciona **Create** y después **Upload from your computer**.
3. Selecciona el ZIP sin alterar la carpeta interna `feedback-design/`.
4. Confirma que el skill se instaló y actívalo cuando corresponda.
5. Prueba con un archivo pequeño: «Aplica Feedback Design Skill; conserva todo el texto y rediseña solo la forma».

Referencia oficial: https://help.openai.com/en/articles/20001066-skills-in-chatgpt

## Si tu producto no ofrece la sección Skills
Puedes trabajar con las instrucciones en `SKILL.md` y las referencias en una conversación o proyecto compatible.
Eso **no equivale a instalar una skill**. La disponibilidad de Skills y herramientas de creación depende de
las funciones habilitadas para tu cuenta y entorno.

## Controles esenciales
- Usa los archivos de origen de tus materiales para cotejar cifras, nombres y orden.
- Para PPTX editable, exige texto, diagramas y tablas nativos; no aceptes una imagen plana.
- Las tipografías Baskerville MT Std y Akzidenz-Grotesk Pro deben instalarse legalmente aparte.
- El logo Feedback requiere autorización; conserva su versión SVG sin modificaciones.
- La plantilla 12×12 contiene datos simulados y no debe tratarse como un resultado real.

Plantillas independientes: https://maxiandradeps4-blip.github.io/visual1/feedback-skill/#instalacion

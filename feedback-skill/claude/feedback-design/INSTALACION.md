# Instalar y utilizar Feedback Design Skill

Este paquete contiene instrucciones de diseño para asistentes de IA compatibles con archivos
de skills, instrucciones persistentes o proyectos con documentación de referencia.

## Ruta general
1. Descarga el ZIP del sitio, descomprímelo.
2. Conserva la carpeta `feedback-design` con `SKILL.md`, `references/` y `assets/`.
3. Agrega la carpeta a la ruta de skills de tu entorno, si esa función está disponible,
   o adjunta todos sus archivos a un proyecto de ChatGPT u otro asistente compatible.
4. Al encargar piezas, pide: **"Aplica Feedback Design Skill"**.
5. Adjunta PPTX/PDF/textos originales y, si corresponde, el logo SVG original y las imágenes
   con sus derechos de uso.

## Importante
- Una carpeta ZIP por sí sola no instala ni habilita generadores de PPT o imágenes.
- El resultado depende de la herramienta con que abras el skill.
- Las fuentes no se incluyen: deben estar legalmente instaladas por el diseñador.
- Para usarlo en diferentes computadores, descarga nuevamente la versión pública o conserva
  el ZIP y los archivos de origen.

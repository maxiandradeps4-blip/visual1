# Feedback Design Skill · Claude · v1.2.0

Versión de la identidad gráfica Feedback preparada para **Claude.ai** y **Claude Code**.

**Incluye**: `SKILL.md`, referencias editoriales, pautas de collage, visualización de
datos, presentación y diagramas, tokens de color y **logo SVG original**.

## Instalación
- **Claude.ai**: Personalizar > Skills > + > Crear skill > Subir skill; selecciona el ZIP sin descomprimir.
- **Claude Code**: descomprime la carpeta `feedback-design` en `.claude/skills/`
  o `~/.claude/skills/`.

Consulta `references/claude-integracion.md` para los detalles.

## Prioridades
1. Conserva exactamente texto, cifras, fechas, notas, logotipos y orden originales.
2. Usa Baskerville MT Std + Akzidenz-Grotesk Pro cuando estén disponibles, blanco
   como base, coral `#F04D51` y cian `#0BB0D2` como acentos.
3. Mantén collages fotográficos con recortes limpios, sin difuminados ni rostros
   protagonistas cuando el encargo así lo indique.
4. Usa gráficos sobrios, legibles, con escalas correctas y sin inventar datos.
5. Para presentaciones editables, produce elementos nativos; no llames editable a una lámina plana.

Las fuentes tipográficas comerciales no están incluidas. El logotipo SVG solo debe
usarse en piezas autorizadas. Las capacidades de exportación dependen de Claude y
de las herramientas activas, no del ZIP.

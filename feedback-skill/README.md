# Feedback Design Skill · v1.0.0

Sistema de instrucciones gráficas para diseñar **collages editoriales, presentaciones, portadillas, diagramas y piezas visuales** con el lenguaje Feedback.

**Descarga:** visita la carpeta `downloads/` o el sitio de este repositorio. El paquete ZIP contiene la carpeta `feedback-design/` y su archivo principal `SKILL.md`.

## Qué hace
- Interpreta encargos de diseño siguiendo la retícula editorial, el contraste y la economía de recursos de Feedback.
- Define criterios específicos para collage editorial, cultura visual chilena, minería, comunicación, economía y territorio.
- Rediseña presentaciones preservando íntegramente información, orden y estructura salvo permiso expreso.
- Prepara diseños 16:9, 1:1, 9:16, 3:4 y formatos especiales, sin inventar contenido.

## Cómo utilizarlo
1. Descarga el ZIP y descomprímelo.
2. Abre `feedback-design/SKILL.md` como instrucción principal.
3. Añade toda la carpeta al entorno que acepte skills/instrucciones y materiales de referencia. Si tu herramienta no admite instalar skills, adjunta estos Markdown a un proyecto o conversación.
4. Describe la pieza, entrega el contenido original y adjunta, cuando corresponda, las referencias de marca y fotografías verificadas.

No es una extensión ejecutable ni crea imágenes de manera autónoma fuera del asistente compatible que lo utilice. Las herramientas disponibles determinan si puede exportar PNG, PPTX, SVG u otros formatos.

## Alcance y marcas
- Colores: coral `#F04D51` y cian `#0BB0D2`.
- Títulos: Baskerville MT Std Regular. Cuerpo: Akzidenz-Grotesk Pro.
- Tipografías y marcas son de sus respectivos titulares. **El paquete no incluye archivos de fuentes ni logos originales.**
- Nunca se presupone autorización para crear fotografías periodísticas falsas ni para alterar datos.
- Para producción pública, usar assets originales suministrados y validar licencias y permisos.

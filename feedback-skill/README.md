# Feedback Design Skill · v1.2.0

Sistema editorial de Feedback para ChatGPT y Claude. **No modifica contenidos ni datos sin autorización.**

Web: https://maxiandradeps4-blip.github.io/visual1/feedback-skill/

## Contenido del sitio
1. Principios de diseño, collages e identidad, con fuentes tipográficas oficiales.
2. Manual de gráficos interactivo (barras, líneas, anillo, dispersión, tablas y diagramas) y descargas SVG.
3. Aplicaciones, generador de instrucciones y comparaciones de ejemplo.
4. Skills para ChatGPT y Claude, además de plantillas editables y recursos vectoriales.
5. Control de calidad, condiciones de uso y notas de actualización.

## Instalación
- ChatGPT: abre Skills → Create → Upload from your computer, si la función está disponible. Ver [guía](skill/INSTALACION.md).
- Claude.ai: usa Personalizar → Skills → + → Crear skill → Subir un skill. Ver [guía](claude/feedback-design/references/claude-integracion.md).
- Claude Code: extrae `feedback-design/` en `.claude/skills/` o `~/.claude/skills/`.

## Identidad
- Coral `#F04D51`, cian `#0BB0D2`, blanco y negro.
- Baskerville MT Std Regular / Akzidenz-Grotesk Pro. No se distribuyen fuentes comerciales.
